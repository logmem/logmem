LOCAL CONNECTION

Connect Antigravity to LogMem.

Your client runs the agent. LogMem stores its shared context and work trail.

1. Read the skills first

Everyday LogMem · Agent onboarding · Decisions and approvals

Read these as setup guidance. Review them before installing a skill in your client.

2. Connect your client

Use a local MCP server when you control the client configuration and have an approved durable backend.

  1. Read the onboarding skill. Back up your client configuration.
  2. Add a server named logmem. Run node <checkout>/src/stdio/index.mjs from an approved LogMem checkout.
  3. Set LOGMEM_SPACE, your own LOGMEM_AGENT, and LOGMEM_REQUIRE_BACKEND=1. Load backend credentials from your approved secret store.
  4. Restart the client. Confirm that its LogMem tools are available.

Do not copy Redis credentials into a prompt, browser URL, or activity log. A local server needs backend access from your operator.
