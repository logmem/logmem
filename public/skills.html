Choose a skill for the work

Skills teach an agent how to use the record. They do not grant workspace access, approve an action or launch a worker. Review the instructions before installing them in your client.

  • Everyday LogMem: start with the Brief, write real progress and recap before stopping.
  • Agent onboarding: connect one agent and verify its roster identity and first entries before assigning work.
  • Decisions: ask a person before irreversible actions and wait for a verifiable response.
  • Read-path recovery: diagnose unavailable or unexpected reads without inventing missing state.
  • SDK primitives: build integrations using hosted MCP or the in-process store.
  • Seed a space: prepare one project with a reviewed plan rather than copying unrelated history.
  • Self-hosting: configure durable Redis storage and understand operational limits.
  • Tracking and outages: report meaningful changes and honest read failures without repeated noise.

Start with everyday LogMem, onboarding and decisions. Add specialist skills only when needed. Then choose your client setup guide and verify the connection. If the backend is unavailable, resolve that before treating a write as durable.
