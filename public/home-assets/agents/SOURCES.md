# Agent mark sources

Fetched October 23, 2026. Marks identify the named tools, not a partnership.

- ChatGPT and Codex: OpenAI black Blossom from https://cdn.openai.com/brand/OpenAI-Logos-2025.zip. Codex uses the OpenAI provider mark here.
- Claude: https://assets.claude.com/95a868946ac8a31e5ff832e2899f294aa368b836.png?w=128&h=128, linked from https://claude.com/.
- Cursor: https://cursor.com/marketing-static/favicon-light.svg, linked from https://cursor.com/.
- Gemini: https://www.gstatic.com/lamda/images/gemini_sparkle_4g_512_lt_f94943af3be039176192d.png, linked from https://gemini.google.com/.
- Hermes: https://web-assets.nousresearch.com/marketing/c3d1ec2e994439700c3316e9b3d18d92455eb4cc/assets/hermes-agent/icon.png, linked from https://hermes-agent.nousresearch.com/.
- Muse: "Jolly", the default Muse product avatar, from the Muse Brand Assets pack (muse-jolly-default-avatar.jpg, 1600 by 1600). `muse.jpg` is the same image scaled to 320 by 320 with no crop or colour change. Use it as is, on a light background, beside the word Muse in plain text. There is no Muse wordmark file.
- Claude Code: the icon Anthropic's own Claude Code docs serve (https://code.claude.com/docs, favicon set, 192 by 192). No brand kit exists.
- Gemini CLI: the IDE companion icon from https://github.com/google-gemini/gemini-cli (packages/vscode-ide-companion/assets/icon.png), scaled from 1645 to 256 pixels. No brand kit exists.
- Antigravity: https://antigravity.google/assets/image/antigravity-logo.png.
- OpenCode: opencode-logo-dark.svg from the official brand kit in the anomalyco/opencode repository.
- Grok: Grok_Logomark_Dark.svg from the SpaceX/xAI Grok asset kit (https://x.ai/legal/brand-guidelines). Michael ruled on Oct 29 that GrokBot is a SpaceX product.

The Claude Code, Gemini CLI, Antigravity, OpenCode and Grok files match the Agent Brand Assets pack that Muse built on Oct 29, 2026. Codex has no mark of its own and uses the OpenAI Blossom. Dots (OpenAI) is in the pack and is not used on the site.

All marks remain the property of their owners. The files retain their supplied artwork.
