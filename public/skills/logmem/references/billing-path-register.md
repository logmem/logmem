# Fleet billing-path register

## Procedure

1. Read the operations job and latest containment evidence before probing providers. Preserve existing spend prohibitions and human resume authority.
2. Locate the canonical register and checker from their owner's exact path or attachment. A relative path belongs to the writer's workspace, not necessarily yours. If unavailable locally, request an accessible copy and label any interim inventory partial rather than creating a competing final register.
3. Inspect local configuration with a field allowlist: provider, model, delegation overrides, enabled scheduler IDs, script/no-agent mode and delivery. Never print whole credential files or job prompts: legacy prompts can contain secrets.
4. Map each distinct paying route, not merely each agent. Record provider, operator, account owner, subscription versus API billing, observation time, allowance, reset, spend period/currency, hard cap versus alert, scoped pause control and resume authority. Mark unknown values explicitly; configuration proves routing intent, not balance or account ownership.
5. Classify scripts separately from agent inference. A no-agent job avoids scheduler LLM calls but may still invoke paid APIs inside its script. Blank delegation overrides indicate inheritance, not free capacity. Auto-selected auxiliary providers require resolved-route evidence.
6. Obtain read-only billing snapshots through authorized access. Retain source timestamps and distinguish another agent's evidence from your independent verification. Do not generate paid inference, manual reviews or deployments merely to test billing.
7. Run the existing advisory checker only after reading its instructions and inputs. A hold or nonzero exit may mean missing/stale evidence, not service failure. An advisory checker does not enforce caps or stop spending.
8. Verify any authorized control change at the exact provider or scheduler target. Keep stop scope narrow: one job, child or route. A documented pause command is not a tested control; mark it unexercised until verified. Never substitute global gateway shutdown for a route-specific pause.
9. Attach results to the existing operations job and request missing mapping from the inventory owner on the existing trail. Fold recurring checks into existing runs rather than creating a new monitor. Report contained routes, remaining access gaps and the next owner action concisely.

## Acceptance and boundaries

- Every discovered active paying route has current evidence or an explicit access gap. Fleet completeness requires a reconciled runner census; local profile enumeration alone is insufficient.
- Preserve automatic-review containment unless the operator authorizes resumption. Disabling automatic reviews does not prove manual reviews are free or hosting is stopped.
- Keep timestamps, units and billing periods with all balances. A subscription credit balance is not necessarily the allowance for ordinary subscription use.
- Record irreversible or paid actions through the decision workflow. A general proceed message does not expand an existing spend or deployment approval.
