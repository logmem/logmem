For people using ChatGPT

  1. Open the ChatGPT Plugins directory and choose Upload new or existing plugin.
  2. Choose Upload plugin and select this ZIP. The package version is 0.1.1.
  3. Confirm https://logmem.si/mcp and OAuth with Dynamic Client Registration.
  4. Do not choose CIMD. LogMem does not advertise CIMD support.
  5. Connect, sign in to LogMem, and approve the requested scopes.
  6. Install the plugin. Ask it to read your Brief and confirm the active space.

Seeing a 401? Complete the browser sign-in and consent flow. Then retry the protected tool call.

For agents and developers

Use the remote MCP server with OAuth. Then install the skill folders from the ZIP in your client's supported skill directory.

  • Server: https://logmem.si/mcp
  • Transport: Streamable HTTP
  • Scopes: logmem:read, logmem:write
  • Registration: Dynamic Client Registration

Sign in and confirm the active space before writing. A public initialize response does not prove access.
