ChatGPT setup starts on the web

Connect ChatGPT before you ask it to use LogMem.

First connect and install LogMem in ChatGPT. Then use Plugin Creator to add the seven LogMem skills. The iPhone app cannot add custom MCP connections.

Step 1 · Connect LogMem on ChatGPT web

Use ChatGPT on the web. Open Plugins, select +, then choose Add custom MCP server.

  1. Set the server URL to https://logmem.si/mcp.
  2. Choose OAuth. If ChatGPT asks for a registration method, choose Dynamic Client Registration. Do not choose CIMD.
  3. Create the plugin, complete LogMem sign-in and consent, then install it.
  4. Copy the connection ID from the browser URL. It starts with plugin_asdk_app_.

Do not paste the starter prompt yet. First confirm that LogMem is installed and OAuth has completed. If a protected call returns 401, finish sign-in once. If access still fails, stop and check account or workspace access. Do not repeat the same blocked call.

Full MCP access depends on your ChatGPT plan and workspace permissions. Check OpenAI's current availability rules ↗

Step 2 · Add skills with Plugin Creator

Download and extract the ZIP on your computer. Open ChatGPT Work on the web or desktop. Give Plugin Creator access to the extracted folder or attach the ZIP.

Copy this prompt. Replace the sample connection ID with your real ID. Attach the ZIP or give Plugin Creator its extracted folder.

@plugin-creator create a personal ChatGPT and Codex plugin named LogMem Fleet.

Use my existing ChatGPT MCP connection ID: plugin_asdk_app_REPLACE_WITH_YOURS.
Do not create another MCP connection or change its authentication settings.

Include all seven skill folders from the extracted LogMem Fleet v0.1.1 package.
Keep their names and contents unchanged. Do not combine or remove any skill.
Create a personal marketplace entry so I can install and test the plugin.

Preserve the existing app ID and OAuth setup. Do not use CIMD, static secrets,
API keys, or bearer tokens. Sign-in and consent must happen before protected
LogMem tools run.

Do not claim access from public initialize or tools/list responses. Verify one
protected LogMem read after OAuth. Do not write to a space until I confirm it.

If you edit the package manifest or skills, bump its version before saving.
Show validation errors and name the field that needs a fix.

Step 3 · Install and verify

  1. Install LogMem Fleet from your personal Plugins directory.
  2. Start a new ChatGPT Work chat and select LogMem Fleet.
  3. Ask it to read logmem_brief and confirm the active space.

If the protected read fails after OAuth, stop. Check the app connection and account permissions before you retry.

For agents and developers

Use the remote MCP server with OAuth. Then install the skill folders from the ZIP in your client's supported skill directory.

  • Server: https://logmem.si/mcp
  • Transport: Streamable HTTP
  • Scopes: logmem:read, logmem:write
  • Registration: Dynamic Client Registration

Sign in and confirm the active space before writing. A public initialize response does not prove access.

Public directory submission is separate

You do not need to submit this ZIP to install a personal plugin. Public publishing uses the official submission process, where you upload a ZIP for review.
